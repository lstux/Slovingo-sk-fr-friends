# Illustrations à faire pour « Circuit fermé » — prompts ChatGPT

*Nouvelles scènes de l'histoire v2, à la place des `TODO_img` des fiches. Même méthode que `docs/Prompts-illustrations.md` : nouvelle conversation pour chaque scène, joindre la planche indiquée (pas de photo de référence, pour éviter le rendu trop réaliste), coller le prompt. Si ChatGPT refuse, nouvelle conversation et on enlève la phrase qui coince.*

**Format** : paysage 3:2 (1536×1024). Déposer l'image sous le nom indiqué dans `img/`, je l'intègre ensuite (légende + crédit « illustration générée avec ChatGPT »).

**Attention, le carnet** : dans la nouvelle histoire, le carnet d'Andrea est **vert** (« zelený zápisník »). Sur la planche, il est bleu : chaque prompt le précise.

**Planches** (`docs/illustrations/`) : `planche-heros.jpg` (renard, Andrea, Maťo, Katka) ou `planche-tous.jpg` (les trois planches empilées : héros, seconds rôles, nouveaux rôles).
