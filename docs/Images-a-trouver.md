# Images à trouver — Zajka Friends

77 images à trouver pour 78 fiches (la photo de halušky sert deux fois). Les deux images de l'introduction (le renard, la hase) sont déjà en place.

Pour chaque fiche, le tableau donne le nom de fichier déjà prévu (`TODO_img/…` dans la fiche), le sujet, le type d'image et des mots-clés de recherche en anglais et en slovaque. Le slovaque marche souvent mieux sur Commons pour les lieux.

## Les trois types d'images

- 📍 **Lieu réel** : il faut une photo du vrai lieu (la fontaine de Košice, le château de Bratislava…). Une image générée ou un autre lieu ne marche pas : la fiche en parle, et le coin slovaque aussi.
- 🌿 **Générique** : n'importe quelle photo libre du sujet fait l'affaire (un éclair, un blaireau, une montre). C'est le plus facile à trouver.
- 🎨 **Ambiance** : une scène d'atmosphère sans lieu précis (un feu de camp la nuit, un refuge éclairé). Une photo libre convient, une illustration générée aussi, dans le style des bannières.

## Où chercher

On prend tout ce qui est gratuit et utilisable pour un projet non commercial.

| Source | Licence | À noter |
|---|---|---|
| [Wikimedia Commons](https://commons.wikimedia.org/) | CC0, CC BY, CC BY-SA, domaine public | Le meilleur choix pour les lieux slovaques. Peut s'utiliser directement avec `Special:FilePath`. Citer l'auteur. |
| [Openverse](https://openverse.org/) | Licences Creative Commons | Moteur de recherche qui couvre Commons, Flickr et d'autres. Pratique pour tout chercher d'un coup. |
| [Flickr](https://www.flickr.com/search/?license=1%2C2%2C3%2C4%2C5%2C6%2C9%2C10) (filtre « licences Creative Commons ») | CC BY, CC BY-SA, CC BY-NC… | Beaucoup de photos de voyage en Slovaquie. |
| [Unsplash](https://unsplash.com/) | Licence Unsplash | Gratuit, citation non obligatoire mais appréciée. Surtout pour les sujets génériques. |
| [Pexels](https://www.pexels.com/) | Licence Pexels | Même principe qu'Unsplash. |
| [Pixabay](https://pixabay.com/) | Licence Pixabay | Même principe. Bien pour les animaux et les objets. |
| Illustration générée (ChatGPT, Gemini) | Libre pour le projet | Seulement pour les images 🎨 Ambiance. Même style que les bannières : Zootopia version ado, couleurs sobres. |

**Attention aux licences « NC » (non commercial)** : elles conviennent tant que le cours reste gratuit. Si un jour le cours devient payant, ces images devront être remplacées. Pour éviter ce travail, mieux vaut préférer CC0, CC BY ou CC BY-SA quand on a le choix.

**Évite les visages reconnaissables**, surtout ceux d'enfants ou d'ados : on cherche des lieux, des objets, des animaux.

## Comment l'intégrer

- **Image de Commons** : on remplace la ligne `@ TODO_img/…` par l'adresse `https://commons.wikimedia.org/wiki/Special:FilePath/<nom du fichier>`, suivie d'une légende.
- **Image d'une autre source** : on télécharge le fichier dans `img/` (environ 800 px de large, en JPG), puis on écrit `@ img/<nom>.jpg | Légende`.
- Dans les deux cas, on ajoute une ligne dans `img/credits.md` : fiche, fichier, source, auteur, licence.
- Format conseillé : paysage (plus large que haut).

Tu peux me donner une liste de liens : je fais l'intégration et les crédits.
