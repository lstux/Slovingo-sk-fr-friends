## Parler de technologie

! Server momentálne nefunguje.
> Le serveur ne fonctionne pas pour le moment.
> server = serveur
> momentálne = pour le moment
> nefunguje = ne fonctionne pas

! Potrebujeme bezpečné pripojenie.
> Nous avons besoin d'une connexion sécurisée.
> potrebujeme = nous avons besoin
> bezpečné = sécurisée
> pripojenie = connexion

! Tvoje heslo by malo byť dlhšie.
> Ton mot de passe devrait être plus long.
> tvoje heslo = ton mot de passe
> by malo byť = devrait être
> dlhšie = plus long

! Dáta sa ukladajú na server.
> Les données sont enregistrées sur le serveur.
> dáta = données
> sa ukladajú = sont enregistrées
> na server = sur le serveur
